# Homelab

A collection of Docker Compose configurations for self-hosted homelab services. This repository contains ready-to-deploy stacks for various services including reverse proxy, media automation, DNS, monitoring, and file management.

## Quick Start

1. **Install Docker** - See [docker-compose/README.md](docker-compose/README.md) for installation instructions
2. **Deploy Traefik** - Start with the reverse proxy (required for most other services)
3. **Deploy Other Stacks** - Add services as needed

For detailed instructions, see the [docker-compose documentation](docker-compose/README.md).

## Requirements

- Docker and Docker Compose installed
- Linux host (tested on Ubuntu Server)
- Optional: Portainer for web-based container management
